# VK Group Parser

Мини-приложение VK для поиска сообществ через `groups.search`.

## Установка
1. Загрузите `index.html` в публичный GitHub-репозиторий.
2. В Settings → Pages выберите Deploy from a branch → `main` → `/ (root)`.
3. Полученный HTTPS URL укажите в настройках размещения VK Mini App.
4. Открывайте приложение через VK, а не напрямую через GitHub Pages.
